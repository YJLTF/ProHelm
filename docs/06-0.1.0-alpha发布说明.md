# ProHelm（项舵）0.1.0-alpha 发布说明

> 日期：2026-11-15｜通道：alpha（内测）｜安装包：Windows x64（NSIS / MSI）
> 这是 M1「核心可用版」的第一个内测版本，面向 10 位内测用户（PMP 备考群 / 项目经理社群）。

## 1. 这个版本是什么

ProHelm 是基于 PMP 体系（PMBOK 8）的 AI 原生、本地优先桌面项目管理工具。0.1.0 alpha 覆盖
M1 出口标准的全部功能线：

- **五焦点领域工作区**：启动 → 规划 → 执行 → 监控 → 收尾，方法论即信息架构
- **WBS 与进度**：树形 WBS（自动编码）、看板拖拽、甘特图（CPM 关键路径红色高亮、依赖连线、
  里程碑菱形）、FS/SS/FF/SF 依赖（环检测）、计划基线
- **核心工件**：项目章程（分节 + AI 起草）、干系人登记册（权力/利益方格）、风险登记册
  （概率×影响 5×5 热力图、五类应对策略）、方法论裁剪器（预测/敏捷/混合预设）
- **AI 舵手（BYOK）**：PMP 教练问答（自研知识库、流式输出）、章程 AI 起草、WBS 拆解；
  一切 AI 产出先落草稿→预览→采纳/弃用，AI 永不直接写库；API Key 只存操作系统钥匙串
- **挣值管理（EVM）**：工时台账 + 基线 → PV/EV/AC、SPI/CPI/EAC/VAC、挣值完成率、S 曲线
- **数据安全**：SQLite 单文件备份/恢复（恢复前自动再备份）、全量 JSON 数据包导入导出、
  项目 Markdown 报告与任务 CSV、**每日自动快照**（保留 14 份，可在设置关闭）、
  **关闭驻留托盘**（点 ✕ 隐藏到托盘继续运行，可在设置关闭；托盘菜单：显示主窗口 / 立即备份 / 退出）
- **PMP 术语速查**：内置 41 条自研术语详解（知识库页），工具界面中带虚线下划线的名词
  悬停即出释义、点击直达详解——不懂的方法论名词随用随学
- **驾驶舱**：跨项目统计、风险雷达、人员负荷、里程碑标记
- **快速起步**：新建项目向导（空白 / 4 个行业模板：软件敏捷、软件预测、乙方咨询、设计创意）

## 2. 安装

- Windows：`ProHelm_0.1.0_x64-setup.exe`（NSIS）或 `.msi`；系统要求 Win10+ 与 WebView2（系统自带）
- 首次启动：数据落在 `%APPDATA%\com.prohelm.desktop\`，无注册、无联网要求（AI 功能除外）
- ⚠️ alpha 包未做代码签名，SmartScreen 首次提示时选择"仍要运行"

## 3. 已知边界（alpha 版有意为之）

- AI 仅支持 OpenAI 兼容协议（GLM/DeepSeek/Qwen/OpenRouter/Ollama 等）
- 甘特图为只读（改期请在任务表单操作）；依赖行内编辑暂仅支持创建时指定 FS 前置
- 排程按日历天（无工作日历）；EVM 以"人时"为价值单位，金额换算后续版本
- 部分更新为 COALESCE 语义：字段一旦填写，暂不支持清空为空（可改值）
- Windows 之外的 macOS（DMG）/Linux（AppImage）安装包待平台验证
- 自动更新（tauri-updater）待签名证书就绪后接入，alpha 期间请从发布页手动更新

## 4. 隐私与数据主权（请内测用户放心）

- 项目数据全部存本地 SQLite；备份与数据包导出不含 AI 溯源与本机设置
- API Key 只存 OS 钥匙串，不落数据库、不进数据包
- **无任何自动埋点上报**：设置页"使用统计"全部由本机操作日志聚合（仅次数与天数，无内容文本），
  由你决定是否复制反馈给团队

## 5. 反馈渠道与诊断信息

1. 遇到 bug：截图 + 操作步骤发到内测群
2. 性能/数据问题：设置页 → 使用统计 → 「复制诊断信息」，把匿名 JSON 一起发来
3. 每周 15 分钟线上访谈（S6 期间），重点收集：新建项目向导、EVM 是否看得懂、AI 起草质量
