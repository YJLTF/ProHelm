# ProHelm（项舵）用户指南 · 0.1.0 alpha

> 面向 5~50 人团队的项目经理与核心成员。全程离线可用；AI 功能需自带 API Key。
> 路线：**5 分钟起步 → 五个焦点领域 → AI 舵手 → 挣值管理 → 数据安全**。

## 1. 五分钟起步

1. **新建项目**：左侧「项目」页 → 新建项目 → 选起步方式（空白或行业模板）→ 填名称与开发方法 → 创建。
   行业模板会自动生成任务树（含依赖）、风险清单和章程脚手架。
2. **拆任务**：进入项目 → 「规划」页签 → 列表视图 → 顶部输入框建任务；
   行内控件可缩进（WBS 层级）、上移/下移、标记里程碑（◆）。
3. **排期**：编辑任务时填工期（天）、起止日期、预估工时、前置任务（FS）；
   切到甘特视图看关键路径（红色）与依赖连线。
4. **存基线**：排期确认后到「监控」页签 → 保存当前为基线（挣值管理的对比基准）。
5. **干起来**：「执行」页签看板拖任务流转；完成后任务自动计入进度。

## 2. 五个焦点领域（主导航）

| 页签 | 放什么 | 关键操作 |
|---|---|---|
| 启动 | 项目章程、干系人登记册、方法论裁剪 | 章程分节编辑 + AI 起草；权力/利益方格拖动干系人；按开发方法勾选流程集 |
| 规划 | WBS 列表 / 甘特图双视图、风险登记册 | 建任务与依赖、R 编号风险 + 5×5 矩阵热力图 |
| 执行 | 看板 | 拖拽流转（待办 → 进行中 → 已完成） |
| 监控 | 健康指标、基线、EVM、报告导出 | 逾期/到期统计、基线快照、挣值曲线、Markdown/CSV 导出 |
| 收尾 | 收尾核对与复盘 | 项目归档（状态改为已关闭） |

## 3. AI 舵手（BYOK：自带 Key）

1. **配置**：设置页 → AI 模型 → 选供应商预设（GLM/DeepSeek/Qwen/OpenAI/OpenRouter/Ollama）→
   粘贴 API Key → 测试连接 → 保存。Key 只写操作系统钥匙串，不落数据库。
2. **PMP 教练**：任意页面右下角舵手悬浮按钮打开侧边栏，可直接问方法论问题
   （如"里程碑和交付物有什么区别？"），也可结合当前项目上下文提问。
3. **章程起草**：启动页签 → 章程编辑器 → 「AI 起草」——结合项目信息、干系人与风险生成分节草稿。
4. **WBS 拆解**：规划页签 → 「AI 拆解」→ 输入需求文本 → 生成两级任务草稿 → 勾选采纳。
5. **铁律**：AI 只产草稿，采纳/弃用由你决定；每次生成都记录在设置页「AI 使用记录」可溯源。

隐私：默认脱敏外发（项目名/人名 → 代号）；一切生成先预览。

## 4. 挣值管理（EVM）：让进度和成本"看得见"

前提：已保存基线 + 任务填了预估工时与起止日期。

1. **登记工时**：监控页签 → 登记工时 → 选任务、日期、小时数（支持补录）。
   工时是 EVM 的"实际成本（AC）"，同时累计到任务的实际工时与驾驶舱人员负荷。
2. **看指标**：
   - **SPI**（进度绩效）：<1 进度落后，>1 超前；**CPI**（成本绩效）：<1 花超了
   - **EAC** 完工估算：按当前 CPI 推算最终要花多少；**VAC** 为负即超支预警
   - **S 曲线**：灰=计划 PV，绿=挣值 EV，红=实际 AC；蓝色虚线是"今天"
3. 常用判读：EV 线在 PV 下 → 落后；AC 线在 EV 上 → 超支。两条指数 ≤0.95 时建议先看风险登记册。

## 5. 数据安全

- **每日自动快照**（默认开启）：每天首次启动自动备份整库到数据目录 `backups/`，保留 14 份；设置页可关。
- **手动备份/恢复**：设置页 → 数据与备份 → 立即备份；恢复前会自动再备份一次当前库。
- **搬家/归档**：导出全量数据包（JSON，含项目/任务/依赖/风险/干系人/章程/基线/工时，不含 AI 溯源与本机设置）；
  新机器导入即可接管。
- **报告**：监控页签导出项目报告（Markdown）与任务清单（CSV，Excel 可直接打开）。

## 6. 常见问题

- **怎么改项目信息 / 暂停 / 关闭项目？** 项目详情页标题右侧「编辑」（或列表卡片上的铅笔）：
  可改名称、编号、方法、预算、日期、简述，并流转状态（规划中 / 进行中 / 已暂停 / 已关闭）。
- **怎么退出应用？** 默认点 ✕ 是隐藏到系统托盘（左键托盘图标恢复窗口，右键菜单可退出）；
  若在设置里关闭「关闭窗口时驻留系统托盘」，点 ✕ 即直接退出。
- **重复打开会新开一个吗？** 不会。ProHelm 是单实例应用：再次启动会自动把已打开的窗口
  带到前台（即使它正驻留在托盘）。
- **数据存在哪？** Windows：`%APPDATA%\com.prohelm.desktop\prohelm.db`，单文件，可直接复制备份。
- **断网能用吗？** 全部功能可用，仅 AI 生成需要联网（配 Ollama 可全离线）。
- **任务能清空字段吗？** alpha 暂不支持"清空"，可改值；删除字段内容请编辑为空串以外的占位。
- **基线能建几个？** 随意；EVM 默认对比最新基线，也可在下拉中切换。
- **怎么卸载干净？** 控制面板卸载应用后，删除上述数据目录即完成（先导出数据包）。
